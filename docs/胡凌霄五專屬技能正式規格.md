# 胡凌霄｜五項專屬技能正式規格

版本：1.0  
角色：女性角色03－胡凌霄  
定位：高速突擊・虎牙穿透彈藥專精  
武器：AR-03「獵牙」突擊步槍  
設計原則：五項技能全部服務於高速射擊、穿透彈道與連續擊殺，不提供第二套流派。

## 一、核心戰鬥規則

- 胡凌霄為中距離突擊型火力輸出角色。
- 專屬彈藥名稱：虎牙穿透彈。
- 專屬彈藥為消耗品；技能二啟動時裝填，裝填量有限，使用完畢須補充物資。
- 專屬彈藥命中後可沿直線貫穿最多3名敵人；每穿透一名敵人，後續傷害遞減。
- 終極技能消耗怒氣值，不免費補充專屬彈藥。
- 本文件的數值為首版平衡基準，後續依實際戰鬥測試調整。

## 二、五項專屬技能

### 1. 虎之直覺｜被動
連續命中敵人累積專注值。達到門檻後進入「虎之直覺」狀態，射擊速度提高20%，短暫未命中或停止攻擊後專注值逐步衰退。擊殺不直接重置累積。

### 2. 虎牙穿透｜主動／專屬彈藥
消耗虎牙穿透彈，將指定數量的普通彈匣替換為穿透彈。穿透彈可貫穿直線上的最多3名敵人，第二名起傷害遞減。彈藥耗盡後自動恢復普通彈，不可免費生成專屬彈藥。

### 3. 疾風連射｜主動
短時間提升胡凌霄射速，持續5秒。效果期間仍消耗一般彈匣；不得突破彈匣容量，也不會複製彈藥。結束後進入冷卻。

### 4. 獵影追擊｜主動
鎖定目前最近的有效目標，進行一段快速精準連射。每發子彈仍遵守彈匣與彈藥消耗規則；若目標被擊倒，後續射擊轉向下一個有效目標。此技能不額外賦予穿透，穿透效果只由虎牙穿透彈提供。

### 5. 虎嘯彈幕｜終極
消耗怒氣值，在短時間內進行高強度連續射擊。若當前裝填的是虎牙穿透彈，終極射擊沿用穿透效果；若沒有專屬彈藥，則使用普通彈，不會免費補充穿透彈。怒氣值透過戰鬥命中與擊殺累積。

## 三、技能連動

虎之直覺累積專注值 → 虎牙穿透裝填專屬彈藥 → 疾風連射提升射速 → 獵影追擊清理殘存目標 → 虎嘯彈幕集中爆發。

## 四、平衡與限制

- 穿透上限首版為3名敵人，避免無限貫穿。
- 穿透傷害逐目標遞減，避免對密集敵群造成失衡傷害。
- 疾風連射與虎嘯彈幕均受實際彈匣限制。
- 虎牙穿透彈為消耗資源，必須透過物資系統補充。
- 怒氣值不與專屬彈藥共用，避免終極技能直接免費補彈。
- 裝甲型、特殊感染者與Boss仍可被穿透命中，但依敵人防禦係數計算傷害。

## 五、整合狀態

本文件確立胡凌霄五項專屬技能的正式設計方向與首版規則。此文件本身是正式規格，不代表遊戲中的戰鬥按鈕、彈藥庫存、怒氣計量、技能冷卻與實際命中效果已完成程式實作；上述執行層需另行整合及測試後才能標示為可玩。
