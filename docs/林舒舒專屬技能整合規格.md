# 林舒舒專屬技能整合規格

## 啟用規則
- 採用「加入隊伍即可使用」方案。
- 林舒舒必須已由主線劇情招募、編入戰鬥隊伍且保持存活，才可使用主動戰鬥技能與被動危險預感。
- 未加入、未出戰或倒地時，技能不生效。
- 沿用既有玩家金幣；技能階級獨立存於 `profile.linShuyuSkillLevel`，內部角色 ID 保留 `lin-shuyu`。

## 五階技能培養
| 階級 | 解鎖內容 |
|---|---|
| Lv.1 | 被動「危險預感」；主動「弱點標記」最多標記3隻喪屍、持續8秒，隊伍傷害+15%；可用「精準點射」 |
| Lv.2 | 弱點標記目標受到隊伍傷害+20% |
| Lv.3 | 弱點標記最多5隻；危險預感警戒距離提高 |
| Lv.4 | 精準點射傷害提高至基礎攻擊4倍 |
| Lv.5 | 解鎖「全域狙察」：標記目前戰場所有喪屍10秒，冷卻45秒；需角色Lv.30才能使用 |

## 冷卻與操作
- 弱點標記：冷卻20秒，快捷鍵Y。
- 精準點射：冷卻15秒，快捷鍵U。
- 全域狙察：冷卻45秒，快捷鍵I。
- 危險預感：偵測接近喪屍並提示，提示間隔6秒。

## 升級與存檔
- 角色Lv.10開放技能培養；終極技能需角色Lv.30及技能Lv.5。
- 五階費用：2,000／3,000／5,000／8,000／12,000 G。
- 金幣不足不扣款；存檔失敗回復本次金幣與技能階級。
- 舊存檔缺少技能欄位時預設Lv.0。

## 探索物資搜索
目前版本尚未具備可互動探索搜索點，因此物資搜索技能先保留為角色定位與後續擴充項目，不會憑空生成物資或修改庫存。

## 相容性
- 主角穿透彈技能與劉牧晴召喚系統維持獨立。
- 角色顯示名稱統一為「林舒舒」，內部 ID 與既有立繪檔名維持相容。
- `index.html` 與 `zombie.html` 必須完全同步。
