# 劉牧晴極寒冰凍彈與角色專屬技能欄測試規格

## 本次範圍
- 建立獨立技能測試頁 `skill-test.html`，不修改正式遊戲入口 `index.html`、`zombie.html`。
- 提供主角、林舒舒、劉牧晴及尚未定案角色的技能說明分頁。
- 未定案角色只顯示待確認狀態，不臆造技能。

## 劉牧晴專屬技能：極寒冰凍彈
- 類型：主動型、單一專屬彈種。
- 啟動方式：手動啟動；啟動後8秒內劉牧晴射出的子彈轉為冰凍彈。
- 結束後恢復普通射擊；不另建特殊彈藥庫存。
- 測試參數：冷卻20秒。
- 彈藥沿用角色原本彈匣概念。

## 五階效果
1. Lv.1：普通喪屍減速30%、2.5秒；淡藍彈體、短冰霜尾跡。
2. Lv.2：減速45%、3秒；亮藍彈道與冰晶粒子。
3. Lv.3：普通喪屍凍結1.2秒；命中冰晶碎片與目標結霜。
4. Lv.4：命中點70像素內普通喪屍凍結1.5秒；冰霜衝擊波。
5. Lv.5：命中點100像素內普通喪屍凍結2.2秒；藍白高亮冰晶彈與大型冰封特效。

裝甲型、特殊感染者與Boss不會完全凍結，只受短暫減速。凍結時間不無限累加。

## 測試頁操作
- 角色分頁：查看各角色專屬技能完整說明。
- 技能等級選擇：切換劉牧晴Lv.1～Lv.5視覺/控制效果。
- 啟動冰凍彈：開啟8秒特殊射擊模式。
- 射擊測試：生成測試彈道並驗證目標減速、凍結及範圍效果。
- 目標狀態辨識：凍結目標顯示大型冰藍外框、冰晶放射線、「❄ 凍結中」標籤及剩餘秒數；減速目標顯示「減速中」與倒數；正常目標標示「正常」。\n- 凍結計數：畫面同步顯示目前凍結數量，例如「目前凍結：2 / 4」。\n- 直接觸發狀態：不依賴子彈命中，可將目前等級效果直接套用到測試喪屍，方便確認狀態顯示與解凍倒數。\n- 重置畫面：清除測試目標狀態與彈道。

## 限制與後續

- 此次強化的是測試台的狀態可視化與驗證入口，不代表正式遊戲戰鬥整合已完成。正式遊戲戰鬥整合仍需在下一階段接入角色射擊、喪屍控制、技能冷卻與存檔資料。
- 本分支不合併至正式版，等待測試驗收。
