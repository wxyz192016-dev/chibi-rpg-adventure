# 人物圖鑑角色詳細資料統一規格

## 適用範圍
本規格適用於目前所有角色，以及未來新增的每一名角色。新增角色時必須沿用相同欄位順序、敘述風格、取得狀態與分頁架構。

## 角色資料欄位
依照角色實際已確認的資料顯示，沒有資料的欄位直接省略，不得顯示「未知」、「尚未設定」或空白占位內容。

1. 角色編號／姓名
2. 性別、年齡、生日、生肖等已確認基本資料
3. 外貌特徵
4. 服裝設定
5. 性格特質
6. 生存專長
7. 戰鬥定位
8. 角色特色
9. 加入條件

欄位可因角色設定而省略不適用項目，但不得任意新增未經確認的資料。

## 敘述規則
- 使用繁體中文及台灣常用語。
- 採正式角色設定集風格，客觀、精簡、易讀。
- 以第三人稱描述角色，不使用未確認的推測設定。
- 角色加入條件必須保留，清楚說明取得或招募方式。
- 加入條件只說明必要解鎖條件，不附加劇情摘要、劇情背景或劇情進度說明。
- 未取得角色顯示「尚未取得」；已取得角色顯示「已取得」。主角標示「主角」。
- 不顯示未知資料、未設定占位文字或空白欄位。
- 不顯示人物背景故事、劇情摘要、劇情進度或劇情解鎖敘述。
- 不顯示角色能力數值、等級數值、生命值、攻擊力、武器傷害、彈匣容量或彈藥數量。
- 不在角色資料分頁重複列出專屬技能內容。

## 分頁架構
人物圖鑑固定保留三個分頁：
- 角色資料：依本規格呈現角色設定及加入條件。
- 角色養成：維持既有養成內容，獨立顯示。
- 專屬技能：維持既有技能內容，獨立顯示。

## 新增角色檢核
每次新增角色時，必須確認：
- 角色資料採用上述欄位與順序。
- 僅填入已確認資料，缺漏欄位直接省略。
- 已填寫角色加入條件。
- 已設定取得狀態。
- 沒有劇情摘要、未知占位文字或角色數值。
- 角色養成及專屬技能仍分頁獨立。
- 不因人物圖鑑文字調整而變更角色數值、戰鬥機制、招募機率或劇情流程。
