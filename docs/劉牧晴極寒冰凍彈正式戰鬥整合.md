# 劉牧晴極寒冰凍彈｜正式戰鬥整合規格

## 整合範圍
- 已接入正式戰鬥入口 `index.html` 與同步入口 `zombie.html`。
- 劉牧晴必須已召喚、加入戰鬥隊伍且存活，並至少解鎖技能 Lv.1，才能啟動。
- 專屬技能等級存入既有玩家存檔欄位 `liuMuqingSkillLevel`；舊存檔自動補預設值 0，不覆蓋既有進度。
- 戰鬥檢查點保存技能剩餘啟動時間、冷卻與喪屍控制狀態。

## 技能運作
- 主動啟動後 8 秒內，劉牧晴射出的普通子彈轉為冰凍彈。
- 技能效果結束後恢復普通射擊；冷卻 20 秒（自啟動起總計 28 秒）。
- 不增加特殊彈藥庫存，不改變既有彈匣與換彈流程。
- 快捷鍵：O；戰鬥介面亦提供「極寒冰凍彈」按鈕。

## 五階效果
1. Lv.1：普通與快速喪屍減速 30%，持續 2.5 秒。
2. Lv.2：普通與快速喪屍減速 45%，持續 3 秒。
3. Lv.3：普通與快速喪屍凍結 1.2 秒。
4. Lv.4：命中點 70 像素範圍內普通與快速喪屍凍結 1.5 秒。
5. Lv.5：命中點 100 像素範圍內普通與快速喪屍凍結 2.2 秒。

裝甲型、特殊感染者及 Boss 不會完全凍結，只受到 25% 短暫減速 1.2 秒。凍結不會累加堆疊成永久狀態；後續命中只刷新控制到期時間。

## 視覺辨識
- 冰凍彈使用高亮冰藍色彈道與光暈。
- 凍結喪屍停止移動及攻擊，身體轉為冰藍色，顯示冰晶外框、放射冰晶線、「凍結中」標籤與剩餘秒數。
- 減速目標顯示「減速中」標籤。
- 戰場左上角持續顯示目前凍結喪屍數量。

## 解鎖與升級
- 劉牧晴角色需達 Lv.10 才能解鎖第一階技能。
- 技能升級沿用現有金幣升級機制，費用依序為 2,000／3,000／5,000／8,000／12,000 G。
- 技能資料可從人物圖鑑的「劉牧晴專屬技能」分頁查看；未召喚時可查看說明，但不能升級或在戰鬥啟動。

## 驗證界線
- GitHub Actions 的同步檢查與 JavaScript 語法檢查通過，才可視為程式靜態驗證成功。
- 實際瀏覽器戰鬥操作仍需進行人工驗收；不可將 CI 通過等同於完整遊戲操作驗收。
