# 《末日倖存者：Z計畫》正式版武器系統規格

- 文件狀態：已確認，納入專案開發規格
- 實作狀態：尚未實作；本文件提交不代表遊戲程式已修改
- 適用版本：正式版
- 核心方案：A — 主角身體與持槍姿勢固定，只替換武器圖片

## 1. 設計原則

1. 主角立繪固定使用目前主角 PNG，不因裝備武器而重製。
2. 主角身體、站姿、位置與尺寸固定。
3. 武器圖片與主角立繪分離，武器以獨立素材呈現並切換。
4. 切換武器時只替換武器圖片及對應武器資料，不改變主角身體姿勢。
5. 原有單人戰鬥、Canvas 戰鬥畫面、技能、存檔及其他既有機制應予保留。
6. 新增武器以新增素材及武器資料為主，不應要求重新製作主角 PNG。

## 2. 起始武器

- 主角初始裝備：手槍。
- 目前主角所持有的那把槍，正式設定為主角起始武器。
- 起始武器需顯示在主角手部對應位置，並沿用既有攻擊與彈藥流程。
- 不在本規格中臆定該手槍的型號或真實規格；傷害、射速、射程、彈匣容量及換彈時間由後續遊戲平衡設定。

## 3. 武器素材規格

建議素材目錄：

```text
武器資料夾/
├── 手槍.png
├── 突擊步槍.png
├── 霰彈槍.png
└── 狙擊步槍.png
```

素材要求：
- PNG 透明背景，單張只包含武器，不包含人物。
- 統一朝向、比例基準與顯示錨點。
- 依主角手部位置設定武器圖片的固定顯示座標。
- 更換素材不得造成主角立繪縮放、位移或姿勢變化。
- 若素材尚未提供，不得以未驗證的圖片路徑宣稱武器已整合完成。

## 4. 首批武器種類規劃

| 武器 | 定位 | 狀態 |
|---|---|---|
| 手槍 | 起始武器、基礎作戰 | 已指定為起始裝備；素材與實際顯示仍須驗證 |
| 突擊步槍 | 中距離、連續射擊 | 規劃中 |
| 霰彈槍 | 近距離、高單發傷害 | 規劃中 |
| 狙擊步槍 | 遠距離、高單發傷害 | 規劃中 |

上述武器定位為設計方向，實際數值尚未定案。

## 5. 武器資料欄位

每把武器應有獨立資料紀錄，至少包含：

- weaponId：唯一識別碼
- name：顯示名稱
- image：武器 PNG 路徑
- damage：單發傷害
- fireInterval：射擊間隔／射速參數
- range：有效射程
- magazineCapacity：彈匣容量
- reserveAmmo：備用彈藥
- reloadTime：換彈時間

數值需由後續平衡階段設定，不在本文件預設未確認數值。

## 6. 切換與彈藥規則

1. 玩家從背包或武器欄選擇已持有武器並裝備。
2. 裝備後立即替換主角手上的武器圖片。
3. 同步更新目前武器的傷害、射速、射程、彈匣與彈藥資訊。
4. 每把武器分別保存彈匣內彈藥與備用彈藥，切換時不得互相覆蓋或混用。
5. 切換武器不得重置主角生命、戰鬥進度、技能冷卻或其他無關狀態。
6. 若武器未持有、素材載入失敗或資料缺漏，需提供明確處理，不得讓戰鬥流程崩潰。

## 7. 與現有戰鬥系統整合要求

- 維持單一主角操作，不恢復舊版五人小隊。
- 保留既有 Canvas 戰鬥畫面及原有戰鬥流程。
- 武器圖片為獨立繪製層，與主角立繪分開載入及替換。
- 武器攻擊數值需接入既有射擊、傷害、彈藥與換彈機制。
- 不因武器切換改變主角身體姿勢（方案 A）。
- 存檔需能保存目前裝備武器及各武器彈藥狀態；舊存檔應有相容處理，不可直接破壞既有進度。

## 8. 實作與驗收順序

1. 建立武器資料管理結構。
2. 將手槍設定為主角起始武器。
3. 建立獨立武器圖片載入與固定錨點顯示。
4. 建立背包／武器欄裝備與切換操作。
5. 接通各武器攻擊參數、彈匣、備用彈藥及換彈時間。
6. 整合存檔與舊存檔相容處理。
7. 測試切換、射擊、換彈、彈藥保存、素材載入失敗及重新載入存檔。
8. 驗收通過後才視為正式版武器系統完成。

## 9. 驗收條件

- 主角 PNG 在不同武器間保持相同大小、位置及姿勢。
- 切換武器時只替換武器圖片與武器資料。
- 手槍為新遊戲起始武器。
- 每把武器彈藥獨立保存。
- 攻擊、傷害、射程、射速及換彈依目前裝備武器運作。
- 存檔／讀檔可正確還原裝備與彈藥。
- 不影響既有單人戰鬥、技能及正式版進度。
